Trotteryzowana ewolucja czasowa 2D modelu Isinga w polu skośnym z LTM AI-QEM

Szacowane użycie: 75 sekund na procesorze Heron r2 (LTM AI-QEM: 23 sekundy, ZNE: 52 sekundy). (UWAGA: To tylko oszacowanie. Twój czas wykonania może się różnić.)

Zapoznaj się z dokumentacją API, aby poznać szczegółowe specyfikacje funkcji.

Aby zacząć korzystać z funkcji, postępuj zgodnie z przewodnikiem LTM AI-QEM.

Tło​

Ten samouczek symuluje trotteryzowaną ewolucję czasową modelu Isinga w polu skośnym za pomocą funkcji LTM AI-QEM.

Model Isinga [1], pierwotnie stworzony do zrozumienia ferromagnetyzmu i kwantowych przejść fazowych w materiałach magnetycznych, stał się kamieniem węgielnym współczesnej fizyki układów wielu ciał. Na najbardziej podstawowym poziomie model opisuje siatkę oddziałujących spinów, z których każdy może przyjmować jeden z dwóch stanów i oddziałuje ze swoimi najbliższymi sąsiadami. Dynamika dwuwymiarowych układów Isinga w czasie rzeczywistym staje się coraz trudniejsza do klasycznej symulacji wraz ze wzrostem rozmiaru układu i czasu ewolucji, co czyni je ważnym poligonem doświadczalnym dla symulacji kwantowej. Ponadto, ponieważ hamiltonian składa się z lokalnych pól jednoqubitowych i dwuqubitowych oddziaływań najbliższych sąsiadów, jego ewolucję czasową można w naturalny sposób przedstawić za pomocą sekwencji jedno- i dwuqubitowych bramek kwantowych. Te właściwości sprawiają, że model jest użytecznym testem porównawczym do badania dynamiki kwantowej na dzisiejszym sprzęcie oraz do oceny skuteczności metod mitygacji błędów kwantowych.

Ten samouczek obejmuje następujące kroki:

  • Opisz matematycznie model Isinga w polu skośnym i jego trotteryzowaną ewolucję czasową.

  • Zdefiniuj backend i Qubity, na których zasymulujesz hamiltonian, oraz zwizualizuj je.

  • Zdefiniuj hamiltonian Isinga w polu skośnym za pomocą klasy Qiskit SparsePauliOp.

  • Skonstruuj obwody kwantowe dla ewolucji hamiltonianu za pomocą funkcji Qiskit evolved_operator_ansatz.

  • Zdefiniuj obserwablę odpowiadającą średniej magnetyzacji, ponownie za pomocą klasy SparsePauliOp.

  • Oblicz ewolucję średniej magnetyzacji dla rosnącej liczby kroków Trottera za pomocą funkcji LTM AI-QEM.

  • Zastosuj metodę ekstrapolacji do zerowego szumu (ZNE) do surowych wyników QPU, aby porównać je z mitygacją wykonaną przez funkcję LTM AI-QEM.

  • Wypisz wartości średniej magnetyzacji obliczone algorytmem rzadkiej dynamiki Pauliego (SPD), które służą jako wartości idealne.

  • Zwizualizuj wszystkie wyniki, aby porównać średnią magnetyzację po mitygacji LTM AI-QEM z wynikami bez mitygacji, wynikami po mitygacji ZNE i wynikami klasycznego algorytmu SPD.

Model Isinga w polu skośnym i jego ewolucja czasowa​

Hamiltonian modelu Isinga w polu skośnym jest następujący:

H=gx∑k∈NXk+gz∑k∈NZk+J∑(k,l)∈Ek<lZkZlH = {g_x}\sum_{k\in{N}}{X_k} + {g_z}\sum_{k\in{N}}{Z_k} + J\sum_{\begin{matrix} {(k,l)}{\in}{E} \\ {k<l} \end{matrix}}{{Z_k}{Z_l}}H=gx​k∈N∑​Xk​+gz​k∈N∑​Zk​+J(k,l)∈Ek<l​∑​Zk​Zl​

gdzie JJJ to siła sprzężenia, a gxg_xgx​ i gzg_zgz​ to odpowiednio siły pola poprzecznego i podłużnego. XkX_kXk​ i ZkZ_kZk​ to operatory Pauliego-X i Pauliego-Z działające na Qubit o indeksie kkk. NNN to zbiór indeksów Qubitów, które ewoluują pod działaniem hamiltonianu. EEE to zbiór krawędzi, z których każda jest krotką indeksów Qubitów (k,l)(k,l)(k,l), między którymi dozwolone są oddziaływania dwuqubitowe. Krok 2: Zdefiniuj hamiltonian​

Zdefiniuj hamiltonian Isinga za pomocą klasy Qiskit SparsePauliOp. W tym celu określ kąty theta_x (θx)(\theta_x)(θx​), theta_z (θz)(\theta_z)(θz​) i theta_zz (θzz)(\theta_{zz})(θzz​), które są powiązane odpowiednio z siłą pola poprzecznego (g_x), siłą pola podłużnego (g_z) i siłą sprzężenia Isinga (J). W szczególności θx=2gxΔt\theta_x=2g_x\Delta{t}θx​=2gx​Δt, θz=2gzΔt\theta_z=2g_z\Delta{t}θz​=2gz​Δt i θzz=2JΔt\theta_{zz}=2J\Delta{t}θzz​=2JΔt.

    circuit = evolved_operator_ansatz(ham, reps=step, insert_barriers=False)  # type: ignore

Porównanie wyników​

Aby porównać metody mitygacji, narysuj wykres wyników LTM AI-QEM, ZNE oraz wykonania na sprzęcie bez mitygacji na tle referencyjnych wyników SPD dla każdej liczby kroków Trottera. Kod wypisuje też tabelę kluczowych metryk wydajności do porównania ilościowego.

import matplotlib.pyplot as plt
import numpy as np

def compute_improvement_metrics(
    spd_results, mitigated_evs, zne_evs, noisy_evs
):
    """Quantify how much each mitigation method improves on the unmitigated result.

    Error for each method is |SPD - method| at every Trotter step (SPD is ideal).

    Returns a dict keyed by method name with:
      - mae:               mean absolute error vs SPD
      - rmse:              root mean squared error vs SPD
      - mean_improvement:  mean(err_unmitigated - err_method)   (absolute units, >0 is better)
      - pct_improvement:   100 * (MAE_unmitigated - MAE_method) / MAE_unmitigated
      - error_reduction_factor: MAE_unmitigated / MAE_method    (>1 is better)
      - frac_steps_improved:   fraction of steps where the method beats unmitigated
    """
    spd = np.asarray(spd_results, dtype=float)
    errs = {
        "Unmitigated": np.abs(spd - np.asarray(noisy_evs, dtype=float)),
        "ZNE": np.abs(spd - np.asarray(zne_evs, dtype=float)),
        "LTM AI-QEM": np.abs(spd - np.asarray(mitigated_evs, dtype=float)),
    }
    base = errs["Unmitigated"]
    base_mae = base.mean()
    eps = 1e-12

    metrics = {}
    for name, e in errs.items():
        mae = e.mean()
        metrics[name] = {
            "mae": mae,
            "rmse": float(np.sqrt(np.mean(e**2))),
            "mean_improvement": float((base - e).mean()),
            "pct_improvement": float(
                100 * (base_mae - mae) / max(base_mae, eps)
            ),
            "error_reduction_factor": float(base_mae / max(mae, eps)),
        }
    return metrics

def plot_trotter_results(
    trotter_steps,
    spd_results,
    mitigated_evs,
    mitigated_errs,
    zne_evs,
    zne_errs,
    noisy_evs,
    noisy_errs,
    title="",
    print_summary=True,
):
    """Plot magnetization versus Trotter steps, and the absolute difference from SPD for each method.

    Top: average magnetization for each method.
    Bottom: grouped bars of |SPD - method|, with mean improvement annotated.

    Returns a dict of improvement metrics (see compute_improvement_metrics).
    """
    spd = np.asarray(spd_results)
    steps = np.asarray(trotter_steps)

    metrics = compute_improvement_metrics(
        spd_results, mitigated_evs, zne_evs, noisy_evs
    )

    series = [
        (spd_results, None, "Sparse Pauli Dynamics", "*", "green"),
        (
            mitigated_evs,
            mitigated_errs,
            "Mitigation by LTM AI-QEM",
            "P",
            "royalblue",
        ),
        (zne_evs, zne_errs, "Mitigation by ZNE", "^", "darkorange"),
        (noisy_evs, noisy_errs, "Unmitigated", "X", "red"),
    ]

    fig, (ax1, ax2) = plt.subplots(
        nrows=2, ncols=1, figsize=(12, 10), sharex=True, height_ratios=[2, 1]
    )

    for values, errs, label, marker, color in series:
        ax1.errorbar(
            steps,
            values,
            yerr=errs,
            label=label,
            marker=marker,
            color=color,
            markeredgecolor="black",
            markeredgewidth=0.5,
            ecolor="black",
            capsize=5,
        )

    ax1.set_ylabel("Average Magnetization")
    ax1.set_title(title)
    ax1.grid(alpha=0.3)
    ax1.legend()

    # Bottom: grouped bars with MAE and % improvement in the legend labels
    bars = [
        (mitigated_evs, "LTM AI-QEM", "royalblue"),
        (zne_evs, "ZNE", "darkorange"),
        (noisy_evs, "Unmitigated", "red"),
    ]
    n = len(bars)
    width = 0.8 / n
    for i, (values, key, color) in enumerate(bars):
        offset = (i - (n - 1) / 2) * width
        m = metrics[key]
        if key == "Unmitigated":
            label = f"|SPD - {key}| (MAE={m['mae']:.3f})"
        else:
            label = (
                f"|SPD - {key}| (MAE={m['mae']:.3f}, "
                f"{m['pct_improvement']:+.1f}% vs unmitigated)"
            )
        ax2.bar(
            steps + offset,
            np.abs(spd - np.asarray(values)),
            width=width,
            label=label,
            color=color,
            edgecolor="black",
            linewidth=0.5,
        )
        if key != "Unmitigated":
            pass
        ax2.axhline(
            m["mae"], color=color, linestyle="--", linewidth=1, alpha=0.8
        )

    ax2.set_xticks(steps)
    ax2.set_xlabel("Trotter Steps")
    ax2.set_ylabel("|SPD - method|")
    ax2.set_title(
        "Difference from SPD (closer to 0 is better; dashed = mean error)"
    )
    ax2.grid(alpha=0.3, axis="y")
    ax2.legend()

    fig.tight_layout()
    plt.show()

    if print_summary:
        print(
            f"{'Method':<12}{'MAE':>10}{'RMSE':>10}{'Mean impr.':>12}"
            f"{'% impr.':>10}{'Factor':>9}"
        )
        for name, m in metrics.items():
            print(
                f"{name:<12}{m['mae']:>10.4f}{m['rmse']:>10.4f}"
                f"{m['mean_improvement']:>12.4f}{m['pct_improvement']:>9.1f}%"
                f"{m['error_reduction_factor']:>9.2f}"
            )

    return None
