Benchmark wierności procesu QFT+M za pomocą Orbit, funkcji Qiskit od Quantum Elements

Szacowany czas użycia: 2 minuty na procesorze Heron r3. (UWAGA: To jest tylko szacunek. Twój rzeczywisty czas wykonania może się różnić.) Domyślnie ten samouczek przesyła trzy zadania funkcji Orbit do jednego zadania w trybie wsadowym IBM Quantum Compute Service, po 300 PUB-ów na zadanie, co daje łącznie 900 PUB-ów i 921 600 strzałów.

Ostrzeżenie: Obwody dynamiczne są obecnie funkcją eksperymentalną i podlegają ograniczeniom w Quantum Compute [3], które mogą powodować niepowodzenia zadań. Na przykład błąd 6073 wskazuje, że zadanie przekroczyło limit pamięci sprzętu klasycznego sterowania [4]. Ten notatnik zmniejsza to ryzyko, dzieląc rozmiary obwodów na trzy zadania Quantum Compute w jednej partii [5]. Każde porównanie o stałym rozmiarze pozostaje w jednym zadaniu, podczas gdy duże i małe rozmiary są parowane, aby zrównoważyć obciążenie sprzętu klasycznego sterowania zadań.

Efekty uczenia się​

Po ukończeniu tego samouczka nauczysz się, jak:

  • Przygotować stany produktowe QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩ używane przez próbkowany estymator wierności procesu na rysunku 2a w Ref. [1].

  • Zbudować równoważne implementacje unitarną i dynamiczną kwantowej transformaty Fouriera z pomiarem (QFT+M).

  • Wybrać kubity fizyczne dla obwodów dynamicznych, korzystając z aktualnych danych kalibracji i łączności.

  • Porównać surowe oszacowania wierności procesu QFT+M: unitarne, dynamiczne i dynamiczne wzbogacone o Orbit, wraz ze wzrostem rozmiaru obwodu.

  • Użyć uproszczonego API transpilacji Orbit z mode="raw" i transpilation_mode="validate".

  • Przesłać wiele obciążeń Orbit za pomocą API trybu wsadowego, zachowując każde porównanie trzech strategii o stałym rozmiarze w jednym zadaniu.

  • Sprawdzić metadane Orbit, aby potwierdzić, czy zastosowano dynamiczne odsprzęganie (DD) i łagodzenie błędów pomiaru (MEM).

Tło​

Rysunek 2a w Ref. [1] porównuje wierność procesu idealnego kanału QFT+M z zaszumionymi implementacjami unitarną i dynamiczną. Dla próbkowanej etykiety xxx w bazie obliczeniowej benchmark przygotowuje QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩, stosuje zaszumioną implementację QFT+M i szacuje prawdopodobieństwo pxp_xpx​ uzyskania odpowiadającego idealnego wyniku. Te stany odwrotnej QFT są separowalne i mogą być efektywnie przygotowane za pomocą bramek Hadamarda i wirtualnych obrotów fazowych.

Dla mmm niezależnie próbkowanych etykiet notatnik używa nieobciążonego estymatora wyprowadzonego w Ref. [1]:

F^proc=mm−1(1m∑ℓ=1mpxℓ)2−1m(m−1)∑ℓ=1mpxℓ.\widehat{\mathcal{F}}_{\mathrm{proc}} = \frac{m}{m-1}\left(\frac{1}{m}\sum_{\ell=1}^{m}\sqrt{p_{x_\ell}}\right)^2 - \frac{1}{m(m-1)}\sum_{\ell=1}^{m}p_{x_\ell}.Fproc​=m−1m​(m1​ℓ=1∑m​pxℓ​​​)2−m(m−1)1​ℓ=1∑m​pxℓ​​.

Konstrukcja dynamiczna zastępuje bramki kontrolowanej fazy w unitarnej QFT+M pomiarami w trakcie obwodu i klasycznie warunkowanymi obrotami fazowymi [1]. Dzięki odroczonemu pomiarowi oba obwody mają ten sam idealny rozkład wyjściowy. Forma dynamiczna eliminuje wymóg bramek dwukubitowych typu all-to-all i zamiast tego wykorzystuje O(n)O(n)O(n) pomiarów w trakcie obwodu ze sprzężeniem zwrotnym (feedforward) i bez ograniczeń łączności. Pomiar i sprzężenie zwrotne pozostawiają również długie okresy bezczynności na kubitach, które nie zostały jeszcze zmierzone, przez co DD jest szczególnie istotne.

Związek z rysunkiem 2a. Ten notatnik podąża za protokołem próbkowanej wierności procesu z artykułu, ale jest adaptacją samouczka skoncentrowaną na Orbit, a nie reprodukcją. Na przykład, podczas gdy rysunek 2a używał ibm_kyiv z 2000 strzałami, my używamy nowoczesnego urządzenia ibm_aachen z mniejszą liczbą 1024 strzałów, aby oszczędzić czas QPU.

def balanced_n_groups(
    n_values: list[int], num_jobs: int = 3
) -> list[list[int]]:
    values = sorted(n_values)
    if len(set(values)) != len(values):
        raise ValueError("N_VALUES must not contain duplicates")
    if not 1 <= num_jobs <= len(values):
        raise ValueError("NUM_BATCH_JOBS must be between 1 and len(N_VALUES)")

    max_group_size = (len(values) + num_jobs - 1) // num_jobs
    groups = [[] for _ in range(num_jobs)]
    loads = [0] * num_jobs
    pair_counts = [0] * num_jobs
    remaining = values.copy()

    while len(remaining) >= 2:
        candidates = [
            i
            for i, group in enumerate(groups)
            if len(group) + 2 <= max_group_size
        ]
        if not candidates:
            break
        smallest = remaining.pop(0)
        largest = remaining.pop()
        job_index = min(
            candidates, key=lambda i: (loads[i], len(groups[i]), i)
        )
        pair = (
            [largest, smallest]
            if pair_counts[job_index] % 2 == 0
            else [smallest, largest]
        )
        groups[job_index].extend(pair)
        loads[job_index] += smallest + largest
        pair_counts[job_index] += 1

    while remaining:
        value = remaining.pop()
        candidates = [
            i for i, group in enumerate(groups) if len(group) < max_group_size
        ]
        job_index = min(
            candidates, key=lambda i: (loads[i], len(groups[i]), i)
        )
        groups[job_index].append(value)
        loads[job_index] += value

    return groups

Zbuduj obwody QFT+M​

Dla każdej próbkowanej liczby całkowitej xxx bit_inv_qft przygotowuje stan produktowy QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩ za pomocą Hadamardów, po których następują obroty fazowe. Notatnik następnie dodaje albo standardową unitarną QFT, albo jej semiklasyczny dynamiczny odpowiednik QFT+M.

Obie implementacje pomijają końcową sieć zamiany (swap network). Kolejność wyświetlania bitów klasycznych w Qiskit sprawia zatem, że oczekiwany zmierzony ciąg jest odwrotnością zerowo-dopełnionej binarnej reprezentacji xxx, kodowanej przez format(x, f"0{n}b")[::-1].

def bit_inv_qft(circuit: QuantumCircuit, x: int, conv: str = "LSB") -> None:
    num_qubits = circuit.num_qubits
    circuit.h(range(num_qubits))
    for j in range(num_qubits):
        phase = (
            2 * np.pi * x / 2 ** (num_qubits - j)
            if conv == "LSB"
            else 2 * np.pi * x / 2 ** (j + 1)
        )
        circuit.p(-phase, j)

def build_unitary_qft_circuit(num_qubits: int, x: int) -> QuantumCircuit:
    if not 0 <= x < 2**num_qubits:
        raise ValueError(
            f"x={x} is outside the {num_qubits}-qubit basis range"
        )
    qreg = QuantumRegister(num_qubits, "q")
    creg = ClassicalRegister(num_qubits, "c")
    circuit = QuantumCircuit(qreg, creg, name=f"unitary_qft_{num_qubits}q")
    bit_inv_qft(circuit, x)
    circuit.append(
        synth_qft_full(num_qubits, do_swaps=False), range(num_qubits)
    )
    circuit.measure(range(num_qubits), range(num_qubits))
    return circuit

def _warn_if_precision_loss(max_num_entanglements: int) -> None:
    if max_num_entanglements > -np.finfo(float).minexp:
        warnings.warn(
            "precision loss in QFT."
            f" The rotation needed to represent {max_num_entanglements} entanglements"
            " is smaller than the smallest normal floating-point number.",
            category=RuntimeWarning,
            stacklevel=4,
        )

def synth_dynamic_qft(
    circuit: QuantumCircuit, *, do_swaps: bool = False
) -> QuantumCircuit:
    num_qubits = circuit.num_qubits
    creg = circuit.cregs[0]
    _warn_if_precision_loss(num_qubits - 1)

    for j in reversed(range(num_qubits)):
        circuit.h(j)
        circuit.measure([j], [j])

        if j > 0:
            with circuit.if_test((creg[j], 1)):
                for k in reversed(range(j)):
                    circuit.p(np.pi * (2.0 ** (k - j)), k)

    if do_swaps:
        for i in range(num_qubits // 2):
            circuit.swap(i, num_qubits - i - 1)
    return circuit

def build_dynamic_qft_circuit(num_qubits: int, x: int) -> QuantumCircuit:
    if not 0 <= x < 2**num_qubits:
        raise ValueError(
            f"x={x} is outside the {num_qubits}-qubit basis range"
        )
    qreg = QuantumRegister(num_qubits, "q")
    creg = ClassicalRegister(num_qubits, "c")
    circuit = QuantumCircuit(qreg, creg, name=f"dynamic_qft_{num_qubits}q")
    bit_inv_qft(circuit, x)
    synth_dynamic_qft(circuit, do_swaps=False)
    return circuit

def target_output_bitstring(x: int, n_qubits: int) -> str:
    return format(int(x), f"0{n_qubits}b")[::-1]

def process_fidelity_from_success_probabilities(
    success_probabilities: list[float],
) -> float:
    m = len(success_probabilities)
    if m <= 1:
        raise ValueError(
            "m must be larger than 1 for the process-fidelity estimator"
        )
    succ = np.asarray(success_probabilities, dtype=float)
    return float(
        (m / (m - 1)) * (np.mean(np.sqrt(succ)) ** 2)
        - np.sum(succ) / (m * (m - 1))
    )

Wybierz fizyczne kubity dla obwodu dynamicznego​

Implementacja dynamiczna nie wymaga bramek dwukubitowych, więc jej kubity fizyczne nie muszą tworzyć połączonego podgrafu. Dla każdego rozmiaru obwodu selektor ranguje aktualne kubity backendu, używając wyniku ważonego 80% w kierunku niższego błędu odczytu oraz po 10% w kierunku wyższych T1T_1T1​ i T2T_2T2​. Najpierw wybiera kubity o wysokim wyniku bez bezpośrednich sprzężeń między nimi, gdy to możliwe, co może zmniejszyć narażenie na przesłuchy między sąsiadami, a następnie wypełnia pozostałe pozycje według wyniku.

Warianty dynamic/raw i dynamic/orbit używają dokładnie tego samego wybranego układu dla danego rozmiaru, dzięki czemu ich porównanie jest kontrolowane pod względem układu. Obwód unitary/raw jest natomiast mapowany i trasowany przez transpiler, ponieważ wymaga łączności dwukubitowej. Ten wybór oparty na kalibracji w czasie wykonania jest specyficzny dla tego samouczka; nie jest to stały 40-kubitowy układ ibm_kyiv użyty w eksperymentach z rysunku 2a artykułu.

def value_from_property(raw):
    if raw is None:
        return None
    if isinstance(raw, tuple):
        return raw[0]
    return getattr(raw, "value", raw)

def qubit_property_value(properties, qubit: int, *names: str) -> float | None:
    for name in names:
        try:
            value = value_from_property(
                properties.qubit_property(qubit, name)
            )
        except Exception:
            value = None
        if value is not None:
            return float(value)
    return None

def measurement_error(properties, qubit: int) -> float | None:
    readout = qubit_property_value(properties, qubit, "readout_error")
    if readout is not None:
        return readout
    p01 = qubit_property_value(properties, qubit, "prob_meas0_prep1")
    p10 = qubit_property_value(properties, qubit, "prob_meas1_prep0")
    if p01 is not None and p10 is not None:
        return 0.5 * (p01 + p10)
    return None

def coupling_edges(backend) -> list[tuple[int, int]]:
    coupling_map = getattr(backend, "coupling_map", None)
    if coupling_map is not None:
        try:
            return [(int(a), int(b)) for a, b in coupling_map.get_edges()]
        except Exception:
            pass
    built = backend.target.build_coupling_map()
    return [(int(a), int(b)) for a, b in built.get_edges()]

def neighbor_map(backend) -> dict[int, set[int]]:
    neighbors = {qubit: set() for qubit in range(backend.num_qubits)}
    for a, b in coupling_edges(backend):
        neighbors[a].add(b)
        neighbors[b].add(a)
    return neighbors

def anchored_score(
    value: float | None, *, good: float, bad: float, higher_is_better: bool
) -> float:
    if value is None:
        return 0.0
    if higher_is_better:
        low, high = sorted((bad, good))
        score = (value - low) / (high - low)
    else:
        low, high = sorted((good, bad))
        score = (high - value) / (high - low)
    return float(min(1.0, max(0.0, score)))

def qubit_metrics(backend) -> list[dict]:
    properties = backend.properties()
    rows = []
    for qubit in range(backend.num_qubits):
        t1 = qubit_property_value(properties, qubit, "T1", "t1")
        t2 = qubit_property_value(properties, qubit, "T2", "t2")
        meas_error = measurement_error(properties, qubit)
        measurement_score = anchored_score(
            meas_error, good=0.005, bad=0.05, higher_is_better=False
        )
        t1_score = anchored_score(
            t1, good=0.00025, bad=0.00005, higher_is_better=True
        )
        t2_score = anchored_score(
            t2, good=0.00025, bad=0.00005, higher_is_better=True
        )
        rows.append(
            {
                "qubit": qubit,
                "t1": t1,
                "t2": t2,
                "measurement_error": meas_error,
                "score": 0.8 * measurement_score
                + 0.1 * t1_score
                + 0.1 * t2_score,
            }
        )
    return sorted(rows, key=lambda row: row["score"], reverse=True)

def select_dynamic_qubits(backend, n_qubits: int) -> list[int]:
    ranked = qubit_metrics(backend)
    neighbors = neighbor_map(backend)
    selected = []
    blocked = set()
    for row in ranked:
        qubit = row["qubit"]
        if qubit in blocked:
            continue
        selected.append(qubit)
        blocked.add(qubit)
        blocked.update(neighbors.get(qubit, set()))
        if len(selected) == n_qubits:
            return selected

    for row in ranked:
        qubit = row["qubit"]
        if qubit not in selected:
            selected.append(qubit)
        if len(selected) == n_qubits:
            return selected
    raise RuntimeError(f"Could not select {n_qubits} physical qubits")

Przygotuj benchmarkowe PUB-y​

Dla każdej pary (N, x) notatnik najpierw transpiluje obwody logiczne, a następnie tworzy jeden PUB Sampler dla każdej strategii:

  • unitary/raw: unitarna QFT+M na układzie wybranym przez transpiler, z trasowaniem w razie potrzeby i bez DD ani MEM od Orbit.

  • dynamic/raw: dynamiczna QFT+M na kubitach fizycznych wybranych na podstawie kalibracji, bez DD ani MEM od Orbit.

  • dynamic/orbit: ten sam transpilowany obwód dynamiczny na tych samych kubitach fizycznych, z włączonymi DD i MEM od Orbit.

PUB wzbogacony o Orbit używa transpilation_mode="validate", ponieważ jego mapowanie zostało już wybrane. Orbit waliduje dostarczony obwód fizyczny zamiast go remapować, a następnie stosuje swój potok DD i MEM. Ponieważ tylko wzbogacona krzywa dynamiczna żąda MEM, nie należy tego interpretować jako izolowanego porównania DD kontra brak DD.

PUB-y, opcje per PUB oraz rekordy wyników są przechowywane według indeksu zadania wsadowego. Dla każdego ustalonego NNN PUB-y unitary/raw, dynamic/raw i dynamic/orbit są utrzymywane razem w tym samym zadaniu. Pomocnik grupujący paruje duże i małe rozmiary obwodów, naprzemiennie zmienia ich kolejność i równoważy sumę NNN w trzech zadaniach jako prosty wskaźnik obciążenia sprzętu klasycznego sterowania.

Pobierz wyniki i oblicz wierność procesu​

Pobierz i zweryfikuj każdy wynik grupy kubitów niezależnie, a następnie połącz trzy strumienie zadań poprzez ich rekordy indeksowane zadaniem. Partia pozostaje otwarta, dopóki wszystkie wyniki funkcji są żądane, i jest zamykana w bloku finally po podjęciu próby dla każdego zadania. Dla każdego PUB-a pxp_xpx​ to prawdopodobieństwo przypisane oczekiwanemu ciągowi bitów. extract_counts odczytuje zliczenia zwrócone do wywołującego; dla dynamic/orbit są to zliczenia skorygowane przez MEM, gdy łagodzenie się powiedzie. extract_raw_counts odzyskuje również odpowiadające niezłagodzone zliczenia zapisane w metadanych Orbit. Kod grupuje 20 wartości pxp_xpx​ dla każdej pary (N, label) i stosuje estymator wprowadzony powyżej.

Wykreślony słownik process_fidelity używa zatem surowych zliczeń dla unitary/raw i dynamic/raw, ale zliczeń skorygowanych przez MEM dla dynamic/orbit. Równoległy słownik raw_process_fidelity zachowuje niezłagodzone obliczenie dla każdej strategii i jest przydatny przy oddzielaniu efektu MEM od reszty potoku Orbit. MEM koryguje zwrócony histogram wyjściowy; nie może wstecznie zmienić wyniku pomiaru w trakcie obwodu, który został już użyty przez sprzężenie zwrotne w czasie rzeczywistym.

def extract_counts(pub_result) -> dict[str, int]:
    data = getattr(pub_result, "data", None)
    if data is None:
        raise TypeError("pub_result.data is missing")

    for name in dir(data):
        if name.startswith("_"):
            continue
        register = getattr(data, name)
        get_counts = getattr(register, "get_counts", None)
        if callable(get_counts):
            counts = get_counts()
            if counts:
                return counts

    raise TypeError(
        "No classical register with get_counts() found in pub_result.data"
    )

def extract_raw_counts(pub_result) -> dict[str, int]:
    orbit_metadata = pub_result.metadata.get("quantum_elements_orbit", {})
    mem_report = orbit_metadata.get("measurementErrorMitigation", {})
    return mem_report.get("rawCounts") or extract_counts(pub_result)

def probability_for_bitstring(
    counts: dict[str, int], bitstring: str, n_qubits: int
) -> float:
    total = sum(counts.values())
    if total <= 0:
        return 0.0
    normalized = Counter()
    for measured, count in counts.items():
        key = measured.replace(" ", "")[-n_qubits:].zfill(n_qubits)
        normalized[key] += count
    return float(normalized.get(bitstring, 0) / total)

Wykreśl krzywe wierności procesu​

Wykres pokazuje próbkowany punktowy estymator wierności procesu QFT+M w funkcji liczby kubitów dla trzech strategii. dynamic/raw i dynamic/orbit mają wspólny układ fizyczny dla każdego rozmiaru; unitary/raw używa układu i trasowania wyznaczonego przez transpiler.

W przeciwieństwie do rysunku 2a ten wykres nie pokazuje krzywej unitarnej z DD ani pasm niepewności, a jego surowe krzywe nie są mitygowane pod kątem odczytu. Najlepiej odczytywać go jako porównanie skalowania w stylu rysunku 2a dla tego przepływu pracy Orbit, a nie jako bezpośrednie odtworzenie opublikowanych krzywych.

from datetime import datetime
from zoneinfo import ZoneInfo

closed_at = runtime_batch.details()["closed_at"]  # "2026-07-22T00:08:54.89Z"
closed_dt = datetime.fromisoformat(closed_at.replace("Z", "+00:00"))
closed_local = closed_dt.astimezone(ZoneInfo("America/Los_Angeles"))
labels = ["dynamic/orbit", "dynamic/raw", "unitary/raw"]
colors = {
    "dynamic/orbit": "#26735b",
    "dynamic/raw": "#9b1c31",
    "unitary/raw": "#6e6e6e",
}
pretty_labels = {
    "dynamic/orbit": "Dynamic QFT+M with Orbit",
    "dynamic/raw": "Dynamic QFT+M",
    "unitary/raw": "Unitary QFT+M",
}

series = []
for label in labels:
    values = [process_fidelity[str(n)][label] for n in N_VALUES]
    log_values = [value if value > 0.0 else float("nan") for value in values]
    series.append((label, values, log_values))

nonzero_values = [
    value
    for _, _, log_values in series
    for value in log_values
    if value > 0.0
]
if not nonzero_values:
    raise RuntimeError(
        "No nonzero process-fidelity values found for log inset"
    )
log_floor = min(nonzero_values) / 2

fig, ax = plt.subplots(figsize=(9.8, 5.6))
for label, values, _ in series:
    ax.plot(
        N_VALUES,
        values,
        marker="o",
        linewidth=2.0,
        markersize=5,
        color=colors[label],
        label=pretty_labels[label],
    )

ax.set_xlabel("N qubits")
ax.set_ylabel("Process fidelity")

ax.set_title(
    f"Dynamic QFT Orbit results on {IBM_BACKEND_NAME}\n"
    f"Job finished {finished_time_for_title:%Y-%m-%d %H:%M %Z}"
)
ax.set_xticks(N_VALUES)
ax.set_ylim(bottom=0)
ax.grid(axis="both", alpha=0.25)
ax.legend(loc="upper right")

inset = ax.inset_axes([0.53, 0.31, 0.44, 0.43])
for label, _, log_values in series:
    inset.plot(
        N_VALUES,
        log_values,
        marker="o",
        linewidth=2.0,
        markersize=5,
        color=colors[label],
    )
inset.set_yscale("log")
inset.set_ylim(bottom=log_floor)
inset.set_xlim(min(N_VALUES), max(N_VALUES))
inset.set_title("Log scale; zeros omitted", fontsize=9)
inset.grid(axis="both", alpha=0.25)
inset.tick_params(axis="both", labelsize=8)
inset.patch.set_alpha(0.96)
