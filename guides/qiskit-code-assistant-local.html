Używanie Qiskit Code Assistant w trybie lokalnym

Dowiedz się, jak zainstalować, skonfigurować i używać dowolnego modelu Qiskit Code Assistant na swoim lokalnym komputerze.

Uwagi
  • Qiskit Code Assistant jest w fazie wersji zapoznawczej i może ulec zmianie.
  • Jeśli masz uwagi lub chcesz skontaktować się z zespołem deweloperów, użyj kanału Qiskit Slack Workspace lub powiązanych publicznych repozytoriów GitHub.

Szybki start (zalecany)​

Najprostszym sposobem na rozpoczęcie pracy z Qiskit Code Assistant w trybie lokalnym jest użycie automatycznych skryptów konfiguracyjnych dla rozszerzenia VS Code lub JupyterLab. Skrypty te automatycznie zainstalują Ollama, aby uruchamiać modele językowe, pobiorą zalecany model i skonfigurują rozszerzenie.

Konfiguracja rozszerzenia VS Code​

Uruchom następujące polecenie w terminalu:

bash <(curl -fsSL https://raw.githubusercontent.com/Qiskit/qiskit-code-assistant-vscode/main/setup_local.sh)

Skrypt wykonuje następujące kroki:

  • Instaluje Ollama (jeśli nie jest jeszcze zainstalowane)
  • Pobiera i konfiguruje zalecany model Qiskit Code Assistant
  • Konfiguruje rozszerzenie VS Code do pracy z lokalnym wdrożeniem

Konfiguracja rozszerzenia JupyterLab​

Uruchom następujące polecenie w terminalu:

bash <(curl -fsSL https://raw.githubusercontent.com/Qiskit/qiskit-code-assistant-jupyterlab/main/setup_local.sh)

Ten skrypt:

  • Instaluje Ollama (jeśli nie jest jeszcze zainstalowane)
  • Pobiera i konfiguruje zalecany model Qiskit Code Assistant
  • Konfiguruje rozszerzenie JupyterLab do pracy z lokalnym wdrożeniem

Zaawansowana konfiguracja​

Jeśli wolisz ręcznie skonfigurować lokalne środowisko lub potrzebujesz większej kontroli nad procesem instalacji, rozwiń poniższe sekcje.

Pobieranie z witryny Hugging Face

Wykonaj poniższe kroki, aby pobrać dowolny model związany z Qiskit Code Assistant ze strony Hugging Face:

  1. Przejdź do strony wybranego modelu Qiskit na Hugging Face.
  2. Przejdź do zakładki Files and Versions i pobierz pliki modelu w formacie safetensors lub GGUF.
Pobieranie przy użyciu interfejsu wiersza poleceń Hugging Face

Aby pobrać dowolny dostępny model Qiskit Code Assistant za pomocą interfejsu wiersza poleceń Hugging Face, wykonaj następujące kroki:

  1. Zainstaluj interfejs wiersza poleceń Hugging Face

  2. Zaloguj się na swoje konto Hugging Face

    huggingface-cli login

  3. Pobierz preferowany model z poprzedniej listy

    huggingface-cli download <HF REPO NAME> <MODEL PATH> --local-dir <LOCAL PATH>
Ręczne wdrożenie modeli Qiskit Code Assistant lokalnie przez Ollama

Istnieje wiele sposobów wdrożenia pobranego modelu Qiskit Code Assistant i interakcji z nim. Ten przewodnik pokazuje użycie Ollama w następujący sposób: za pomocą aplikacji Ollama z integracją Hugging Face Hub lub modelem lokalnym, albo za pomocą pakietu llama-cpp-python.

Korzystanie z aplikacji Ollama​

Aplikacja Ollama zapewnia proste rozwiązanie do lokalnego uruchamiania modeli językowych. Jest łatwa w użyciu, a jej interfejs wiersza poleceń sprawia, że cały proces konfiguracji, zarządzanie modelami i interakcja są całkiem proste. Idealnie nadaje się do szybkiego eksperymentowania oraz dla użytkowników, którzy chcą uniknąć zbędnych szczegółów technicznych.

Instalacja Ollama​

  1. Pobierz aplikację Ollama

  2. Zainstaluj pobrany plik

  3. Uruchom zainstalowaną aplikację Ollama

    info
    Aplikacja działa poprawnie, gdy ikona Ollama pojawi się na pasku menu pulpitu. Możesz też sprawdzić, czy usługa działa, przechodząc na adres http://localhost:11434/.

  4. Wypróbuj Ollama w terminalu i zacznij uruchamiać modele. Na przykład:

    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit

Konfiguracja Ollama z integracją Hugging Face Hub​

Integracja Ollama/Hugging Face Hub umożliwia interakcję z modelami hostowanymi na Hugging Face Hub bez konieczności tworzenia nowego pliku modelfile ani ręcznego pobierania plików GGUF lub safetensors. Domyślne pliki template i params są już dołączone do modelu na Hugging Face Hub.

  1. Upewnij się, że aplikacja Ollama działa.

  2. Przejdź do strony wybranego modelu i skopiuj adres URL. Na przykład: https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF.

  3. W terminalu uruchom polecenie:

    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit

Możesz używać modelu hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit lub dowolnego z innych aktualnie zalecanych oficjalnych modeli GGUF: hf.co/Qiskit/mistral-small-3.2-24b-qiskit-GGUF lub hf.co/Qiskit/granite-3.3-8b-qiskit-GGUF.

Konfiguracja Ollama z ręcznie pobranym modelem GGUF Qiskit Code Assistant​

Jeśli ręcznie pobrałeś model GGUF, taki jak https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF, i chcesz eksperymentować z różnymi szablonami i parametrami, możesz wykonać poniższe kroki, aby załadować go do lokalnej aplikacji Ollama.

  1. Utwórz plik Modelfile o następującej zawartości, pamiętając o zaktualizowaniu <PATH-TO-GGUF-FILE> do rzeczywistej ścieżki pobranego modelu.

    FROM <PATH-TO-GGUF-FILE>
    TEMPLATE """{{ if .System }}
    System:
    {{ .System }}

    {{ end }}{{ if .Prompt }}Question:
    {{ .Prompt }}

    {{ end }}Answer:
    ```python{{ .Response }}
    """

    PARAMETER stop "Question:"
    PARAMETER stop "Answer:"
    PARAMETER stop "System:"
    PARAMETER stop "```"

    PARAMETER temperature 0
    PARAMETER top_k 1

  2. Run the following command to create a custom model instance based on the Modelfile.

    ollama create Qwen2.5-Coder-14B-Qiskit -f ./path-to-model-file
    uwaga
    This process may take some time for Ollama to read the model file, initialize the model instance, and configure it according to the specifications provided.

Run the Qiskit Code Assistant model manually downloaded in Ollama​

After the Qwen2.5-Coder-14B-Qiskit model has been set up in Ollama, run the following command to launch the model and interact with it in the terminal (in chat mode).

ollama run Qwen2.5-Coder-14B-Qiskit

Some useful commands:

  • ollama list - List models on your computer
  • ollama rm Qwen2.5-Coder-14B-Qiskit - Delete the model
  • ollama show Qwen2.5-Coder-14B-Qiskit - Show model information
  • ollama stop Qwen2.5-Coder-14B-Qiskit - Stop a model that is currently running
  • ollama ps - List which models are currently loaded
Manually deploy the Qiskit Code Assistant models in local through the llama-cpp-python package

An alternative to the Ollama application is the llama-cpp-python package, which is a Python binding for llama.cpp. It gives you more control and flexibility to run the GGUF model locally, and is ideal for users who wish to integrate the local model in their workflows and Python applications.

  1. Install llama-cpp-python
  2. Interact with the model from within your application using llama_cpp. For example:
from llama_cpp import Llama

model_path = <PATH-TO-GGUF-FILE>

model = Llama(
        model_path,
        seed=17,
        n_ctx=10000,
        n_gpu_layers=37, # to offload in gpu, but put 0 if all in cpu
    )

input = 'Generate a quantum circuit with 2 qubits'
raw_pred = model(input)["choices"][0]["text"]

You can also add text generation parameters to the model to customize the inference:

generation_kwargs = {
        "max_tokens": 512,
        "echo": False, # Echo the prompt in the output
        "top_k": 1
    }

raw_pred = model(input, **generation_kwargs)["choices"][0]["text"]

Use the llama.cpp library​

Another alternative is to use llama.cpp, an open-source library for performing LLM inference on a CPU with minimal setup. It provides low-level control over the model execution and is typically run from the command line, pointing to a local GGUF model file.

There are several ways to install llama.cpp on your machine:

  • Install llama.cpp using brew, nix, or winget
  • Run with Docker: See out the Docker documentation by llama.cpp team
  • Download pre-built binaries from the releases page
  • Build from source by cloning this repository

Once installed, you can use llama.cpp to interact with GGUF models in conversation mode as follows:

# Use a local model file
llama-cli -m my_model.gguf -cnv

# Or download and run a model directly from Hugging Face
llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF -cnv

You can also launch an OpenAI-compatible API server for the model in the following way:

llama-server -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF

Advanced parameters​

With the llama-cli program, you can control the model generation using command-line options. For example, you can provide an initial “system” prompt using the -p/--prompt flag. In conversation mode (-cnv), this initial prompt acts as the system message. Otherwise, you can simply prepend any desired instruction to your prompt text. You can also adjust sampling parameters - for instance: temperature (--temp), top-k (--top-k), top-p (--top-p), repetition penalty (--repeat-penalty), and the seed to use (--seed). The following is an example invocation using these options:

llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF \
  -p "You are a friendly assistant." -cnv \
  --temp 0.7 \
  --top-k 50 \
  --top-p 0.95 \
  --repeat-penalty 1.1 \
  --seed 42

Aby zapewnić prawidłowe działanie naszych modeli Qiskit, zalecamy używanie promptu systemowego udostępnionego w naszych repozytoriach HF GGUF: prompt systemowy dla mistral-small-3.2-24b-qiskit-GGUF, Qwen2.5-Coder-14B-Qiskit-GGUF, granite-3.3-8b-qiskit-GGUF i granite-3.2-8b-qiskit-GGUF.

Ręczne łączenie rozszerzeń z lokalnym wdrożeniem

Użyj rozszerzenia VS Code i rozszerzenia JupyterLab dla Qiskit Code Assistant, aby wysyłać zapytania do lokalnie wdrożonego modelu Qiskit Code Assistant. Gdy masz już skonfigurowaną aplikację Ollama z modelem, możesz skonfigurować rozszerzenia, aby łączyły się z lokalną usługą.

Połączenie z rozszerzeniem Qiskit Code Assistant dla VS Code​

Za pomocą rozszerzenia Qiskit Code Assistant dla VS Code możesz wchodzić w interakcję z modelem i uzupełniać kod podczas pisania. Sprawdza się to dobrze dla użytkowników szukających pomocy przy pisaniu kodu Qiskit w swoich aplikacjach Python.

  1. Zainstaluj rozszerzenie Qiskit Code Assistant dla VS Code.
  2. W VS Code przejdź do User Settings i ustaw Qiskit Code Assistant: Url na adres URL lokalnego wdrożenia Ollama (na przykład http://localhost:11434).
  3. Przeładuj VS Code, przechodząc do View > Command Palette... i wybierając Developer: Reload Window.

Model Qiskit Code Assistant skonfigurowany w Ollama powinien pojawić się na pasku statusu i jest gotowy do użycia.

Połączenie z rozszerzeniem Qiskit Code Assistant dla JupyterLab​

Za pomocą rozszerzenia Qiskit Code Assistant dla JupyterLab możesz wchodzić w interakcję z modelem i uzupełniać kod bezpośrednio w Jupyter Notebook. Użytkownicy, którzy głównie pracują z Jupyter Notebooks, mogą skorzystać z tego rozszerzenia, aby jeszcze bardziej usprawnić pracę z kodem Qiskit.

  1. Zainstaluj rozszerzenie Qiskit Code Assistant dla JupyterLab.
  2. W JupyterLab przejdź do Settings Editor i ustaw Qiskit Code Assistant Service API na adres URL lokalnego wdrożenia Ollama (na przykład http://localhost:11434).

Model Qiskit Code Assistant skonfigurowany w Ollama powinien pojawić się na pasku statusu i jest gotowy do użycia.
