Logowanie dla Qiskit Runtime

Usługi IBM Cloud®, takie jak Qiskit Runtime, generują logi platformy, których możesz używać do badania nieprawidłowej aktywności i krytycznych działań na swoim koncie oraz rozwiązywania problemów.

Możesz skorzystać z IBM Cloud Logs Routing, która jest usługą platformy, aby kierować logi platformy na swoim koncie do wybranego miejsca docelowego, konfigurując dzierżawcę (tenant) określającego, dokąd są wysyłane logi platformy. Więcej informacji znajdziesz w artykule Informacje o Logs Routing.

Możesz skorzystać z IBM Cloud Logs, aby wizualizować logi platformy generowane na swoim koncie i kierowane przez IBM Cloud Logs Routing do instancji IBM Cloud Logs oraz ustawiać alerty na ich podstawie.

Lokalizacje, w których generowane są logi platformy​

IBM Cloud Container Registry generuje logi platformy wyświetlane w Twoich instancjach logowania. Poniższa tabela zawiera listę lokalizacji, w których włączone jest automatyczne zbieranie logów usługi Container Registry.

Generowane logi platformy​

IBM Qiskit Runtime generuje logi usług platformy wyświetlane w Twoich instancjach logowania w następujących konkretnych przypadkach:

  • Gdy zmienia się stan zadania (job).

Przeglądanie logów ze strony Observability​

Informacje o uruchamianiu interfejsu IBM Cloud Logs znajdziesz w sekcji Launching the UI w dokumentacji IBM Cloud Logs.

Pola według typu logu​

Informacje o polach zawartych w każdym logu platformy znajdziesz w artykule Fields that are included in platform logs.
